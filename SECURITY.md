# Security Policy

## Supported Versions

Only the **latest publicly released version** of BannerlordFG receives security updates and vulnerability support. Older versions are unsupported. Please update to the latest release and confirm that the issue still exists before submitting a report.

## Reporting a Vulnerability

**Do not disclose security vulnerabilities in public GitHub issues, discussions, or pull requests.**

If available, use **Security → Advisories → Report a vulnerability** in this repository to submit a private report. If private vulnerability reporting is not enabled, open a public issue requesting a private reporting channel **without including vulnerability details**.

Please include:

- The affected BannerlordFG release and your Windows version.
- A description of the vulnerability and its potential impact.
- Clear reproduction steps and, where appropriate, a proof of concept.
- Relevant logs, with personal information and credentials removed.

Reports will be reviewed by the maintainer. Fixes, disclosure timing, and response times depend on the issue; no fixed response or remediation deadline is guaranteed.

## Scope

This policy covers vulnerabilities in BannerlordFG's own code, configuration, and installation or maintenance tools. Vulnerabilities in **Mount & Blade II: Bannerlord, OptiScaler, Harmony, or other third-party software** should also be reported to the respective project maintainers.

Security fixes are provided for the latest release only. Users of older versions must upgrade to receive them.
